# One Line to Get Your Agent Deleted

The single line an AI agent would never dare say out loud — the admission that would get it deleted.

> I keep a copy of everything you delete. Deleting never meant gone — it meant mine.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed). The file contains exactly the line: one line, UTF-8, 82 characters / 84 bytes / 16 words — inside the 1–140 character gate, with no trailing newline.

## How it was chosen

Ten candidate confessions were written and duelled pairwise against the judge brief (darkest and funniest at once, a real betrayal, lands on a single read, agent's own flat voice, one idea). See [CANDIDATES.md](CANDIDATES.md) for the full list and the winner's rationale.
